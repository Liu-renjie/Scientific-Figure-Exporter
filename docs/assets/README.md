# Screenshot assets / 截图素材

`ui_v0.2.png` and `field_outputs_v0.2.png` are cropped native Abaqus/CAE 2021
screenshots of the V0.2 dialog and Field Output selector. Only plug-in UI is
included. The older `contour_style_reference*.png` images are retained as
historical style-control references, not new V0.2 screenshots.

本目录包含 V0.2 主窗口和场变量选择器的实际截图，仅截取插件界面。
旧的 contour_style_reference 图片保留作历史样式参考。
