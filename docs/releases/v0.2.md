# Scientific Figure Exporter V0.2

Released 2026-10-12 · Tag `v0.2` · Windows / Abaqus CAE 2021 / Python 2.7

## English

V0.2 extends the original viewport exporter with static ODB batching and a more
compact workflow. The previous v0.1 release and tag remain available.

### New and improved

- Discover Field Outputs from the selected ODB Step; select multiple rows with
  mouse drag or Ctrl/Shift, including components and invariants such as
  `S, Mises`, `S, S11`, `U, Magnitude` and `U, U1` when present in the ODB.
- Export current, first, last, every-N or specified 0-based Frames within a Step,
  using consistent view, background, legend, resolution and naming settings.
- Review resolved output filenames and combinations in a read-only export
  plan before writing images. No post-export CSV is generated.
- Use Compact/Standard UI sizing with wrapped descriptions and a persistent
  PNG preview alongside the settings tabs.
- Avoid scanning all Frames by default and avoid loading FieldOutputs merely
  to build the export plan. Reuse a bounded cache of Frame metadata, not field
  values or mesh data. Large meshes still need native Abaqus rendering time.
- Fix the Python 2 Unicode error that prevented the field selector from opening,
  initial dialog height and disabled-contour false export errors.

### Install or update

Download `Scientific-Figure-Exporter-V0.2.zip`, extract it, close Abaqus/CAE,
then run `python install_plugin.py` in the extracted folder. Restart CAE and
open **Plug-ins > Scientific Figure Exporter...**. Existing runtime files are
backed up by the installer. See [installation details](https://github.com/Liu-renjie/Scientific-Figure-Exporter/blob/v0.2/docs/INSTALLATION.md).

The release includes the illustrated Word guide and `SHA256SUMS.txt`.
Internal development files previously used the label v1.2; the public version
for this tested release is V0.2. No old tag is replaced.

### Important limitations

- Only Windows + Abaqus/CAE 2021 + embedded Python 2.7 is the verified target.
- PNG, TIFF, SVG and Windows JPG are available; EPS and animation are not.
- Disable Auto Fit to preserve manual zoom and pan. Preview shows only the
  first selected field/Frame combination, not the entire batch.
- Scan all Frames is optional and can be slow. Fields must exist in the actual
  Frames exported. Existing output files may be overwritten after confirmation.
- With All open viewports + Combined canvas, choose one view at a time.
- The optional Tight layout feature was removed; Combined canvas uses the
  existing viewport layout. Output width and height control image resolution.

## 中文

V0.2 在原有视口出图功能上加入静态 ODB 批量输出，并改进单屏使用体验。
原 v0.1 的发布和标签均保留，不覆盖旧版本。

### 新增与改进

- 从当前 ODB 动态识别场变量，支持鼠标拖选及 Ctrl/Shift 多选；可选择
  ODB 中实际存在的分量和不变量，例如 `S, Mises`、`S, S11`、`U, U1`。
- 支持同一 Step 下的当前帧、首帧、末帧、每隔 N 帧及指定帧索引，按一致的
  视角、背景、Legend、分辨率和命名规则生成静态序列图。
- 真正写图前显示只读导出计划表，核对变量、帧和文件名；不生成导出后 CSV。
- 提供 Compact/Standard 界面尺寸预设、长说明换行及始终在旁侧显示的预览。
- 默认不扫描全部帧，计划表不读取所有场数据；仅缓存少量帧元数据，减少
  重复读取。大模型本身的 Abaqus 等值线计算和渲染耗时仍然存在。
- 修复场变量选择器的 Python 2 Unicode 错误、初始窗口高度，以及等值线
  控件禁用时仍错误阻止导出的问题。

### 安装与更新

下载并解压 `Scientific-Figure-Exporter-V0.2.zip`，关闭 Abaqus/CAE，
在解压目录运行 `python install_plugin.py`，重启后从 Plug-ins 菜单打开。
安装器会备份被替换的运行文件。发布页另附图文 Word 说明及 SHA-256 校验文件。

此前的 v1.2 为内部开发标记，本次公开发布统一为 V0.2，标签为 `v0.2`。

### 注意事项

仅验证 Windows + Abaqus/CAE 2021 + Python 2.7。支持 PNG、TIFF、SVG、JPG；
不支持 EPS 或动画。要保留手动缩放和平移，请关闭 Auto Fit。预览仅显示
首个变量/帧组合，导出时执行完整批次。全帧扫描可能较慢；导出确认后已有
同名文件可能被覆盖。全部视口合并画布时每次选择一个视图。

Tight layout 可选功能已移除，合并画布沿用已有视口布局；输出宽高用于控制
图像分辨率。更多限制与操作见仓库首页及 Word 使用说明。
